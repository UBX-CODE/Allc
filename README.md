## 🚀 Overview

**ALLC** is a full-stack web application designed to revolutionize healthcare scheduling. 
**Book Appointments. Pay Securely. Get Care Faster.** (Jan 2025)

This smart doctor appointment booking platform is built with a focus on modern deployment pipelines, dynamic data handling, and a highly responsive UI to ensure an optimal user experience for both patients and healthcare providers.

## ⚙️ Getting Started (Local Setup)

Want to run ALLC locally? Follow these steps:

### Prerequisites
- Node.js (v18+ recommended)
- Firebase Account
- Stripe API Keys (for testing secure payments)

### Setup Steps

1. **Install dependencies**  
   Fire up your terminal and install all required modules.
   ```bash
   npm install
   ```

2. **Configure Environment Variables**  
   Create or edit your `.env` and `.env.local` files to include your Firebase and payment keys.

3. **Run the Development Server**  
   Start both the Vite frontend and Node.js backend.
   ```bash
   npm run dev
   ```
